# Персональный контроль питания — экспертная система

Учебная программа на Python демонстрирует прямую цепочку рассуждений для общих бытовых подсказок о режиме питания.
## Состав проекта

- `экспертная_система.py` — разбор и сохранение правил, рабочая память, прямой вывод и консольное меню управления правилами.
- `база_правил.txt` — отдельная редактируемая база правил.

## Запуск

Требуется Python 3.10 или новее. Из каталога проекта выполните:

```text
python3 экспертная_система.py
```

Выберите `1`, введите время суток и давность последнего приёма пищи, затем ответьте, хочется ли пить. Все шесть сочетаний первых двух значений приводят к заключению; при ответе `да` программа дополнительно выводит подсказку о воде. Если изменённой базе правил не хватает фактов, программа запросит новый факт; пустой ответ завершает вывод. Пункт `2` показывает правила, пункт `3` позволяет добавить, удалить или отредактировать правило; изменения сразу записываются в `база_правил.txt`.

Проверки запускаются командой:

```text
python3 -m unittest -v
```

## Формат правил

Одно правило занимает одну строку;

```text
ЕСЛИ Время=утро И Последний_приём=давно ТО Ситуация=утренний_перерыв
```

Сравнение значений точное, регистр учитывается после нормализации введённого стартового факта в нижний регистр. Объект — строковый ключ факта, значение — строка. Для одного объекта в рабочей памяти хранится одно значение.
